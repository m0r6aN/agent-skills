TOP 3 BRUTAL FINDINGS
1. HIGH append-only bypass: with recursive_triggers off (the SQLite default), INSERT OR REPLACE and REPLACE INTO delete the conflicting row without firing any BEFORE DELETE trigger. That silently rewrites rows nothing references: a v1 spend with no attempt, TerminalReceipts, Settlements, and PendingEffects. Verification step 3 tests only UPDATE and DELETE.
2. HIGH migration mechanics: the spec never says where journal_mode=WAL runs relative to BEGIN IMMEDIATE. The v1 code sets WAL before it checks anything, so rejecting a malformed or future DB does not "leave it unchanged". Also, v1 creates the table, then the index, then the version without a transaction. A crash in between leaves a table with no index, which the spec calls malformed and rejects forever, although v1 repaired this state itself. "Exact shape" is not defined either, and the stored DDL text depends on CRLF line endings.
3. MEDIUM relational gaps: AttemptOrdinal is a second per-permission counter that nothing ties to SpendIndex (which v1 sets to count+1), so ordinal 1 can bind to spend 3. A NULL SlotAllocationId switches off the slot foreign key. TerminalReceipts and Settlements link only to EffectAttempts, so the store accepts a terminal or settlement for an attempt that has no pending effect.

TOP 3 MOVES
1. Add BEFORE INSERT triggers on all eight tables that RAISE(ABORT) when the new row's primary key or any declared UNIQUE key already exists. Test INSERT OR REPLACE, REPLACE INTO and UPSERT on every table, and show the original row is unchanged.
2. Fix the order: Open, foreign_keys=ON, busy_timeout, BEGIN IMMEDIATE, classify, DDL, user_version=2, COMMIT, and WAL only after the state is accepted. Classify with table_info, index_xinfo, foreign_key_list and trigger names, not DDL text. Add a table-without-index v1 state that is upgraded in the same transaction. Test that a rejected file keeps its header bytes.
3. Add CHECK (AttemptOrdinal = SpendIndex), make SlotAllocationId NOT NULL, and point the TerminalReceipts and Settlements EffectAttemptId foreign keys at PendingEffects(EffectAttemptId). Add a splice test for each.
