TOP 5 BRUTAL FINDINGS
1. The packaged plugin is materially behind the standalone release: it lacks seven functional areas and still exposes home-repo/cwd assumptions that undermine its advertised cross-repo portability.
2. The highest-confidence transplant is the explicit-root and caller-identity hardening; it directly removes silent misrouting, foreign-repo writes, and fixed KONE/operator coupling.
3. The role-authority, worker-envelope, and mutation-scope packages are valuable contract foundations, but the standalone changelog explicitly says mutation scope has no caller, so copying them without wiring creates governance theater.
4. Fireworks worker routing/result contracts are substantial but not ready for wholesale adoption: the standalone records coordinator-role/runtime defects and no shipped caller for evaluateRouting; provider/security decisions also need local ratification.
5. Contract-readers and model-gate hooks are useful bounded additions, but contract-readers has no scheduler integration and hooks are Claude-specific with tests excluded from CI; both need explicit operational ownership.

TOP 5 MOVES
1. Port the standalone 0.4.0 manifest/docs and establish a compatibility branch, then add a package-by-package parity matrix and run each package's typecheck/test/lint in the plugin tree.
2. Port explicit target/plugin roots first across dispatch, registration, projection, verification, skill resolution, approval, and permission profiles; replace fixed Jira identity with foreman-config inputs and add relocation tests.
3. Add foreman-config as the single declaration boundary, then port role-authority and worker-envelopes as schema-only contracts with generated-schema parity and full-population tests.
4. Port mutation-scope-guard only with a named integration parcel that invokes preflight at dispatch and post-hoc after execution; otherwise keep it staged and document the gap.
5. Treat Fireworks routing, contract-readers, hooks, and templates as separate gated parcels: fix recorded defects, ratify provider/security policy, wire callers, and add CI/installation verification before shipping.
