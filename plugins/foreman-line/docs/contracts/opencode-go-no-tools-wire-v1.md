## Fixed private profile

Version`opencode-go-no-tools-wire/v1`; provider`opencode-go`; protocol`openai-chat-completions`; POST exactly`https://opencode.ai/inference/go/openai/v1/chat/completions`; model`mimo-v2.6-pro`. Fixed body: model, exactly one system and one user message,`stream:false`,`max_completion_tokens:1024`,`thinking:{type:'disabled'}`. No history/images/tools/function definitions/tool-choice, sampling knobs, hooks, custom URL or arbitrary body/header fields. No fallback to the old installed Pi URL or`max_tokens`.

Input is a closed owned plain record containing version, requestDigest, decisionDigest, sessionId, system and user. Digests are64lowercase hex; sessionId is1..128ASCII`[A-Za-z0-9._:-]` beginning alphanumeric. Strings are well-formed Unicode, nonempty, no caller getters/prototypes/symbol keys/cycles. The rendered messages JSON is at most4096UTF8 bytes, complete body at most8192. Bind copied serialized bytes and SHA256 to request/decision digests in an opaque installation-private prepared value. Those digests provide correlation/integrity only; they authenticate no route or human.

Headers fixed to JSON accept/content-type, truthful`foreman-line-opencode-go/1` user-agent, the validated stable`x-opencode-session`, calculated content length and installation-supplied bearer credential. Credentials are never part of the prepared value/result/log. A forged/mutated/foreign prepared object refuses before credential or request access. No task-supplied HTTP/credential capability.

## Transport and observations

One prepared sender closure may attempt at most one HTTPS request constructor; mark uncertain exposure immediately before constructor call, including synchronous throws. Pre-abort/invalid preparation/credential failure returns no-send. Any error/abort/timeout after that marker is uncertain, never no-send or automatic retry. Concurrent/second calls are refused; they cause no additional request or credential retrieval. One direct Node HTTPS request, no SDK/agent retries, redirects, proxy discovery or alternate endpoint. TLS verification enabled, agent disabled, bounded response headers,120000ms hard deadline; clear timers/listeners and destroy owned request/response on every terminal path. Late callbacks cannot change the result or restart work.

Non200(including429/5xx), redirected/compressed/wrong content type, malformed/truncated/oversize JSON, identity mismatch, tool output or protocol failures remain uncertain after exposure. Accept only bounded UTF8 JSON(at most65536bytes), exact model, one index0 assistant choice, text only, finish`stop`/`length`. Reuse existing bounded JSON scanner where compatible without editing it; reject duplicate keys and invalid Unicode/numbers. Returned text remains untrusted candidate content. Stop is observed semantic completion; length is incomplete, never succeeded.

Report usage as reported safe-integer prompt/completion/total with consistent sum; completion cannot exceed1024, optional reasoning count cannot exceed completion. Missing/malformed usage is unknown, never zero; optional reasoning count absent is unknown. Do not infer billable dollars, cached credit or settlement from tokens or published prices. Every result retains unknown charge; no money/ledger settlement or authenticated terminal proof is minted. Raw response headers/body/errors/credential contents are not logged or exposed. Existing generic Observation/Charge unions may be reused where they preserve this honesty, without weakening them.

Offline intercepted-request tests prove construction/lifecycle only. The upstream MiMo documentation names the total token field; Go forwarding/enforcement, current account allowance/ExtraUsage, exact route/provider admission and remote installation remain unqualified. Therefore no live call can be admitted by RP-01.
