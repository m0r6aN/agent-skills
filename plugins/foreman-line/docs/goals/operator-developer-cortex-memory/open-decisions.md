## D. Stop ledger (conditions that halt promotion immediately)

1. Required frozen-contract/canon change discovered → stop, report, owner amendment only (four-force taxonomy, INV-1…INV-6, schema retyping).
2. Ambiguous or competing source ownership for a mutation target → stop (see OD-1/OD-2).
3. A needed file is outside a parcel's exact Allowed Files → stop; amendment required.
4. Verification tripwire: a builder's claimed test count does not match disk, or a suite runs with skips in a no-skip gate → stop; wrong-shaped claims are presumptively empty.
5. Security finding that cannot be closed within the parcel's scope → stop; escalate in this goal's records.
6. Any outward-facing action beyond current authorization (cloud write, credential change, provider spend above cap, public publication of private source) → stop.
7. Primary-project protection (AgentTask) threatened by scope expansion → stop.
8. Reviewer consensus demands an unapproved frozen-contract change → stop that parcel; do not bargain it away in rework.
9. Promotion of `opmem/integration` to `main` in `keon-cortex` or `keon-mcp-gateway` triggers Azure auto-deploy (`keon-cortex-AutoDeployTrigger-*.yml`; `deploy-production.yml` / `deploy-staging.yml`) → outside the blanket grant; **stop-for-owner** (merge/deployment boundary ruling, 2026-10-12).
