## 3. Resolution pipeline (map to code)

`resolveRoute(policy, request, { issued_at })` — deterministic, no I/O, injected clock:

1. Structural gates: policy carries the new-representation blocks
   (`REPRESENTATION_INCOMPLETE_REFUSED`), lane ∈ frozen map and request mapped to it
   (`ROLE_LANE_MAP_VIOLATION`), request fields coherent (each malformed input maps to its
   input's named "unknown" refusal — `DATA_CLASS_UNKNOWN`, `CAPABILITY_UNVERIFIED`,
   `INDEPENDENCE_UNPROVEN`, `CONTEXT_UNKNOWN`, `COST_UNKNOWN`).
2. L6 gate first, nothing else evaluated (`LANE_DISABLED_REFUSED`).
3. R5 ceiling gate: a routing class without a ratified `classes[*].ceiling_usd` fail-closes
   (`COST_UNKNOWN`) until an owner value lands (P1 § 4) — never an invented ceiling.
4. Candidate walk (rubric §2/§4 "filters always run first"): every `RouteRef` of the lane's
   declared routes resolves exactly as `validator.ts` `checkLaneRoutes.resolve()` does (a
   `candidate` ref → the route provider's first declared binding; unresolvable →
   `FALLBACK_DANGLING_REFERENCE` / `FALLBACK_PROVIDER_MISMATCH` stops — post-review rework,
   review A F1), then R1–R7 records + identity (zero-match AC2A names, owner-attested hold) +
   endpoint alignment for every resolved binding of the lane's declared routes.
5. Gate phase (rubric §4 step 1): unresolvable-ref stops, then the lane-route `comparability`
   gate (vocabulary + `FALLBACK_SUITABILITY_UNPROVEN` — post-review rework, review A F2 / review B
   RB-4), then the per-lane provider step: slot integrity (`RESIDUAL_FABRICATED_REFUSED`,
   including composed `${lane}_*` names — review A F4), the a54 stop receipts for unset
   pins/preferences, frozen per-lane kind conformance (`ROLE_LANE_MAP_VIOLATION` for any
   undispatched or lane-mismatched `provider_rule.kind` — review A F3); `cheapest-eligible`
   proceeds (the only decidable rule while the declaration slots are typed-unavailable).
6. Selection: rankable **primary**-role bindings (DERIVED — D3 pairing integrity: a
   fallback-role binding is recorded, never selected as the session model), ordered by
   projected cost (L5 dominant key), then the documented stable order. Empty pool → stop
   receipt naming every per-candidate refusal/hold (`REPRESENTATION_INCOMPLETE_REFUSED` if none
   was recorded).
7. Emission: chosen binding + its declared typed fallback, where the fallback must resolve to
