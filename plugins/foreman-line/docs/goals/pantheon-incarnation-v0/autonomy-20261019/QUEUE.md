Each implementation parcel uses its own worktree/branch; serialize shared schemas, manifests, lockfiles and service composition. Clinton Morgan is accountable owner for all tracks; named components below own the work. No additional human maintainer sign-off is invented.

Default dependency order is serial. Independent read-only analysis/test preparation can overlap; the global limit is two workers and one paid call. A parcel that expands beyond a reviewable change is split into children without expanding authority or increasing limits; the queue records the parent/child relationship.

## Common acceptance and rollback

Every shaped spec includes exact allowed files, forbidden surfaces, scope/context hashes, branch/worktree, role/profile, source baseline, commands, expected evidence counts, review focus, risk, capability envelope, exception predicates and rollback. Step 0 is an automated equality check. No new public contract is changed silently. Green checks attest the exact head/config, not another machine or later revision.

Critical/high security findings require repair; material residual-risk acceptance belongs to the owner. Ordinary findings go to bounded rework. Spec gaps within intent are explicit coordinator amendments committed separately; material gaps produce one exception. Tests must include negative and crash paths relevant to the changed boundary. Test count falling unexpectedly is a tripwire; a second unexplained occurrence holds the parcel.

Rollback: stop admitting that profile, revoke its capability/epoch, terminate only owned local workers, preserve spent permissions and unknown charges, revert the reviewed change by ordinary commit if needed, and restore prior pinned image/config. No deleting consumed claims, resetting the shared branch or wiping evidence. Snapshot cleanup occurs only for owned disposable worktrees/containers with verified paths.
