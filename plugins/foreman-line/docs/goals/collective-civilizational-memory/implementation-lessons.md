### P2C runtime composition — October23

Validate ordinary ownership/cleanup/transport failure coverage before allocating
the single formal repair: mocked cleanup cannot establish cleanup correctness.
Passing actual adapter fixtures complements those tests; it cannot replace them.
Type-check variable reuse in finally blocks can keep a behaviorally passing
candidate red; preserve that failure instead of waiving the check. Python signal
handlers can defer native C work, while namespacePID1 ignores default-action
signals; retain measured evidence and separate kernelCPU, Dockerwall and unproved
daemon-cancellation guarantees. Parent stream-wire caps must account for SSE
metadata overhead, not only normalized answer size; a missing capture stays
unknown with its full reservation, even after offline client regression passes.


### P2C additional repair review — October24

A failure test must assert the required safety action even if an earlier teardown
action throws: kill failure must not exempt a wait/reap attempt. Fail-closed public
errors are not proof of subprocess reaping. Do not put independent teardown
actions under a shared try if the first exception suppresses the second. Rejection
tests need otherwise-valid inputs and validator-stage reachability assertions;
malformed envelopes can hide removal of duplicate/depth guards. Test counters
and all-green suites do not substitute for these independent oracles. Both fresh
reviews caught the operator-authored assertion gap; reproduce and retain rather
than weakening the requirement or silently adding another repair.


### Accepted P2C runtime — October24

Keep poll/kill and bounded wait in independent teardown attempts; an exception
from one cleanup action must not suppress another, and timeout0 permits an exit-
race reap without extending the command deadline. Test bool offsets with numeric
ranges that would otherwise pass, versionTrue in complete valid envelopes, and
unknown keys in complete valid symbol objects. Include a finite schema-predicate
inventory before review to avoid repeated masked-oracle findings. Fixed mutation/
normalization seams can demonstrate sensitivity while leaving production files
untouched. Distinguish raw API balance updates from user topup confirmation;
keep preflight before inference and funding-adjusted debit accounting. Final
source/committed/merged tree equality and actual main CI close source acceptance,
not full import readiness or held credential-route clearance.


## Git object snapshot October24

- Raw binary tree closure gives path/object binding; a supplied recursive path
  listing alone does not prove a file belongs to the selected commit. Keep the
  pure validator independent from the future privileged Git acquisition adapter.
- Exact frozen-slots dataclasses can be allocated with object.__new__ without
  initialized fields. Shape validation must classify absent slots before limits;
  seven incomplete combinations with/without oversize sibling are meaningful
  negative controls. Testing an existing frozen field avoids the unrelated
  Python slots/nonexistent-attribute TypeError behavior.
- Git symlink tree record cost is28bytes plus filename, not31. At-limit fixtures
  must assert exact encoded lengths before testing validator outcomes.
- Source JSON framing failure need not cause another paid request: preserve raw
  output, recover only unambiguously decoded exact strings offline, independently
  validate, and retain the conservative booking and original unsuccessful receipt.
- No job steps plus explicit account billing annotation means source CI is
  unverified. Preserve exact reviewed head and stop reruns; local tests/reviews
  do not authorize bypassing the green merge chain. GenSpark credits do not
  settle GitHubActions billing.
