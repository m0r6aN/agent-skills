## F1 — A1.8's status line is itself a stale self-reference (INFO, but pointed)

The document says it is uncommitted; it has been committed since `7fa0ddf`. The commit
message is accurate that ratification did not occur, so no authority was manufactured —
the defect is confined to the document's own status line.

It is worth naming rather than quietly fixing: this is a stale self-description inside the
amendment whose stated purpose is retiring stale self-references, and it is the third time
in this goal's records that the artifact a future `/goal resume` trusts first was wrong about
its own state (the others: the loop directive saying STOPPED while running, and the FK-P0
rework rounds recorded in commit messages with no findings on disk). The pattern is not
carelessness about content; it is that **status lines are written once and then outlive the
state they describe.** A status line that must be hand-maintained is the same defect class
A1.8 diagnoses in prose that enumerates a binding set.

## F2 — §4.1 disclaims itself, and this is currently in force (BLOCKER for anything relying on §4.1)

§4.1 states: *"Appending a row is the only way to change the binding set. An amendment
document that has not produced a row here is a proposal, whatever its own status line says."*

A1.8 changed the charter in four places (header, §4 preamble, §4.1, §10) and appended no row
for itself. By the rule it installs, §4.1 is a proposal. The charter therefore currently
contains a governing section that disclaims its own authority, and the §4 preamble and §10
Gate 1 text now route the binding-set question *through* that section.

Practical blast radius today is small and should not be overstated: D1–D21 are each rowed by
one of the three existing rows, so **no locked decision is actually unsupported**. What is
provisional is the *mechanism*, not the decisions. The cost is paid by the next amendment,
which cannot cite §4.1 as settled procedure.

The prior owner declined to fabricate a row, and that was the right call — a row asserting a
ratification that did not occur would be worse than the gap.
