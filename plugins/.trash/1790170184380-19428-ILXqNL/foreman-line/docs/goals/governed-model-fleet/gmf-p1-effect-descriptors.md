## Effect-descriptor scope (RATIFIED D4/D7)

V1 governs exactly three effect classes, each with its own complete descriptor, permission decision, spend, receipt binding, and denial path (RATIFIED D4; charter A5). Every complete descriptor is canonicalized and hashed and binds the D7 field set; material drift requires a new permission (RATIFIED D7). Runtime-issued `IPermission` is the sole authority; no descriptor, role, envelope, receipt, or evidence confers authority (RATIFIED D2). Execution authority never implies inference; output possession never implies promotion (RATIFIED charter A5/D4).

Error-code note (RESOLVED DR-002, S1/S2/S3 2026-09-16): the Fleet error-code vocabulary is ratified in `gmf-p1-canonicalization-and-error-codes.md` P1-C071 (26-code closed set); `BLOCKED_UNRATIFIED_ERROR_CODE` is retired as an expected code prospectively per P1-C072 (quoted in P0 history only).
